We are pleased to welcome you to the redesigned University of Maryland Libraries Open Data website . The Open Data site has been fully migrated from its previous Sphinx framework to Hugo , a modern static site generator that offers enhanced performance, accessibility, and flexibility. This migration supports an updated user interface and easier maintenance of the website.
